Homepage submission — concise notes

This project is a responsive homepage built with HTML5 and Bootstrap 5.

Images

- The site currently loads images from external URLs; no local image files are included in this repository.
- To use local images instead, add files to an `images/` folder and update the image paths in `index.html`.

Preview with Live Server (VS Code)

1. Install the "Live Server" extension in VS Code.
2. Open this workspace in VS Code.
3. Open `index.html`, then right-click the editor and choose "Open with Live Server", or click "Go Live" in the status bar.

Quick alternative (Python)

```powershell
python -m http.server 8000
# then open http://localhost:8000
```
